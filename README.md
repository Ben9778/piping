## 項目介紹
出於系統安全考慮，企業需要使用內部支付測試環境,這是一個內網穿透小工具,用來搭建開發過程中第三方支付的本地測試環境。支持通過瀏覽器、postman
以及各類主流開發語言如java、python、javascript的請求訪問。
## 項目結構
1.__piping-server__: 支付環境的伺服器端, 主要負責接收外部請求, 並轉發到本地客戶端。

2.__piping-clients__: 支付環境的客戶端, 主要負責向piping-server發送請求, 將伺服器發送的請求數據重定向到本地應用程序端口,再將數據轉發回伺服器。
